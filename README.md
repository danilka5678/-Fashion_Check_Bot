# Fashion Quiz Bot

Телеграм-бот: квиз по миру моды с уровнями, вопросом дня и рейтингом.

## Запуск

1. Создай бота в Telegram у **@BotFather** командой `/newbot` и скопируй токен.
2. Установи Python 3.10+ и зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Задай токен и запусти:
   ```
   # Windows (cmd)
   set BOT_TOKEN=твой_токен
   python bot.py

   # macOS / Linux
   export BOT_TOKEN=твой_токен
   python bot.py
   ```

Бот работает, пока запущен скрипт. Для постоянной работы разверни его на VPS или на хостинге (Railway, Render, Fly.io).

## Что умеет

- `/play`: раунд из 10 случайных вопросов
- Выбор категории: бренды, дизайнеры, история, знаковые вещи
- `/daily`: вопрос дня (одинаковый для всех) и серия дней подряд
- Ежедневное напоминание про вопрос дня (час задаётся `REMINDER_HOUR`, по умолчанию 12)
- `/profile`: уровень, точность, статистика по категориям, сильные и слабые стороны
- `/top`: рейтинг игроков
- После каждого ответа показывается короткий факт

## Как добавлять вопросы

Открой `questions.json` и добавь запись по образцу:

```json
{"cat": "brands", "q": "Текст вопроса?", "options": ["A", "B", "C", "D"], "answer": 1, "fact": "Пояснение после ответа."}
```

- `cat`: `brands`, `designers`, `history` или `items`
- `answer`: номер верного варианта (с нуля)
- Варианты ответов бот перемешивает сам

Перед публикацией сверяй факты по надёжным источникам: в базе стоят 40 стартовых вопросов, и их стоит перепроверить.

## Идеи для развития

- Вопросы по картинкам («угадай бренд по образу»): Telegram принимает фото, нужны только свободные изображения
- Дуэли между друзьями и режим для групповых чатов
- Хранение прогресса в PostgreSQL вместо SQLite
- Адаптивная сложность и поле `difficulty` у вопросов
