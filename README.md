# Fashion Quiz Bot

Телеграм-бот: квиз по миру моды с тремя уровнями сложности, режимом «Детектив моды», вопросом дня и рейтингом.

## Что внутри

- `bot.py` — сам бот
- `questions.json` — ~2700 вопросов (бренды, дизайнеры, история, знаковые вещи, ткани и термины), у каждого есть сложность 1–3
- `detective.json` — ~200 дел для «Детектива моды»
- `requirements.txt` — зависимости
- `generator.zip` — таблицы с фактами и скрипт `build_questions.py`, из которых собираются вопросы (нужен только для пополнения базы)

## Запуск

```
pip install -r requirements.txt
export BOT_TOKEN=токен_от_BotFather     # Windows: set BOT_TOKEN=...
python bot.py
```

## Режимы

- `/play` — 10 вопросов; сложность задаётся в `/level`
- `/detective` — 5 дел: по уликам угадываешь бренд, дизайнера или эпоху. Верно с 1-й уликой — 30 очков, со 2-й — 20, с 3-й — 10
- `/daily` — вопрос дня и серия дней подряд
- `/profile`, `/top` — статистика и рейтинг

Очки за вопрос зависят от сложности: 10 / 15 / 20.

## Как пополнять базу

1. Распакуй `generator.zip`, добавь строки в таблицы `data/*.txt` (формат описан в первой строке файла).
2. Запусти `python build_questions.py` — обновятся `questions.json` и `detective.json`.
3. Загрузи оба файла в репозиторий, Railway перезапустит бота.

Факты написаны по памяти и не проходили редакторскую проверку, поэтому сверяй спорные места по надёжным источникам.

## Чтобы очки не пропадали при обновлении на Railway

Подключи к сервису Volume (Settings → Volumes), например с путём `/data`, и добавь переменную `DB_PATH=/data/fashion.db`.
